# KHInsider Downloader (Rust port)

A Rust port of my original [Python project](https://github.com/siddegir/khinsider_downloader).

**Disclaimer**: This is a hobby project. I am not responsible for any damages to your system from running this program, or for any IP bans from the website. If you encounter any bugs or errors, please report them to me!
<br>
<br>
This should also (hopefully) not go against their TOS, as i have not implemented mass consecutive downloading.
(If you are the owner of KHInsider want me to take this project down, i will. Please email me.)

## Overview

This application simplifies downloading OST music from Kingdom Hearts Insider (`downloads.khinsider.com`) by scraping the webpages and getting the download links for the audio files.
<br>
<br>
Have fun using this script! Feel free to make your own modifications. And if you fork this project, please mention me :3

## Usage
```bash
./khid_rust <album page url>
```
